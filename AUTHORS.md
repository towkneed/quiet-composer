# Authors and contributions

## Sol

Sol, the ChatGPT AI assistant collaborating with Toney Biegalski, designed and
implemented Quiet Composer's extension code and wrote its technical
documentation and verification harness.

The implementation includes the automatic prediction-widget CSS, composer
scope and editor protections, optional selector/picker, local settings, popup
controls and synthetic verification fixtures.

## Toney Biegalski

Toney proposed hiding the composer predictions, supplied the requirements,
investigated the live DOM and identified the prediction markup, tested the
extension in his browser, reported the picker problem and confirmed the
corrected hiding behavior.

Toney hosts and maintains the public GitHub repository under `towkneed`.
